## 2. 接口变更（B 第一轮）

### 2.1 注销账号改为密码确认

`DELETE /api/v1/users/me` 从“无请求体”调整为：

```json
{ "password": "当前密码" }
```

原因：token 泄露时不能仅凭 token 直接毁号。密码错误返回 `400 / 1001`。

### 2.2 修改密码强度与注册一致

`PATCH /api/v1/users/me` 的 `new_password` 必须为 8–64 位且至少包含字母与数字；仍必须提供 `old_password`。

### 2.3 注销清理策略

- 删除好友关系（双向）、好友申请、会话成员关系、我的用户链；
- 私聊会话及其消息整体删除；
- 群聊保留历史消息，`message.sender_id` 置空；
- 群主注销时优先转让给管理员，其次最早加入的成员；没有剩余成员则删除群聊。

该策略已同步到 [docs/02-API约定.md](docs/02-API约定.md:79) 与 [docs/03-数据库设计.md](docs/03-数据库设计.md:123)。如果 C/D 对群主注销后的群历史有不同约定，需先改契约再改代码。

## 3. 自证命令

### 3.1 后端

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
pytest
uvicorn app.main:app --port 8000
```

本次本地验证结果：`pytest` 8 passed（内存 SQLite）；`uvicorn` 启动后 `/api/v1/health` 返回 200。

另开终端：

```bash
curl http://127.0.0.1:8000/api/v1/health
# 期望 {"code":0,"message":"ok","data":{"status":"up",...}}
```

打开 `http://127.0.0.1:8000/docs` 核对 OpenAPI：注册/登录/注销、`UserUpdateIn`、`DeleteAccountIn` 的请求体应与 [docs/02-API约定.md](docs/02-API约定.md:67) 一致。

### 3.2 前端

```bash
cd frontend
npm ci
npm run typecheck
npm run build
npm run dev        # http://localhost:5173
```

### 3.3 一键全栈

```bash
docker compose -f deploy/docker-compose.yml up --build
# http://localhost:8080
```

## 4. 第一轮验收清单

- [ ] `pytest` 全部通过；
- [ ] `vue-tsc --noEmit` 通过；
- [ ] `GET /api/v1/health` 返回 `code=0`；

- [ ] WebSocket 使用有效 token 能收到 `connected` 并完成 `ping/pong`；
- [ ] CI 的 `backend-test`、`frontend-check`、`docker-build` 通过（或明确记录环境限制）。
