# 05 前端界面规范

> Role A 交付物:统一布局、颜色、字体、公共组件与交互规范。  
> 实现入口:`frontend/src/theme/tokens.ts`、`frontend/src/stores/theme.ts`、`App.vue` 的 Naive `themeOverrides`。  
> 图标:`@lucide/vue` + [`AppIcon.vue`](../frontend/src/components/AppIcon.vue)(SVG,禁止 emoji 当图标)。

## 1. 视觉方向

- 产品形态:即时通讯工作台(列表 + 会话 + 侧栏),不是营销落地页。
- 气质:现代蓝白玻璃 —— 冷灰蓝中性表面 + **单一蓝色强调色** + 渐进模糊玻璃层(顶栏),克制渐变、无霓虹描边、无卡片堆叠。
- Hallmark:**modern blue glass** · genre modern-minimal / utilitarian;不采用 Hum。
- 落地页专用 Floor(首屏 hero、约 80 词/屏、图库)对本 IM 壳层 **豁免**,记入本文件即可。
- 可选本地安装 Hallmark skill(不入库):`npx skills add nutlope/hallmark`。

## 2. 设计令牌(禁止组件内硬编码色值)

| Token | Light | Dark | 用途 |

| `--surface` | `#ffffff` | `#1e293b` | 侧栏/顶栏/卡片 |
| `--text` | `#0f172a` | `#e2e8f0` | 主文案 |
| `--text-muted` | `#64748b` | `#94a3b8` | 次要文案/时间 |
| `--border` | `#e2e8f0` | `#334155` | 分割线 |
| `--accent` | `#2563eb` | `#3b82f6` | 主按钮/链接 |
| `--danger` | `#dc2626` | `#f87171` | 危险操作 |
| `--bubble-mine` | `#dbeafe` | `#1e40af` | 本人气泡 |
| `--bubble-other` | `#ffffff` | `#273449` | 对方气泡 |
| `--hover` | `#f1f5f9` | `#273449` | 列表悬停 |
| `--active` | `#e0e9fb` | `#1f3a5f` | 列表选中 |
| `--surface-glass` | `surface 72%` | `surface 70%` | 玻璃层(顶栏,`backdrop-filter` 配合) |
| `--accent-soft` | `accent 10%` | `accent 18%` | 低对比强调底(用户胶囊等) |
| `--accent-soft-hover` | `accent 16%` | `accent 26%` | 低对比强调底悬停 |
| `--bg-decor` | 蓝色双 radial 渐变 | 同左(略强) | 页面底装饰渐变 |
| `--radius-control` | `9999px` | 同左 | **胶囊形**按钮/单行输入 |
| `--radius-surface` | `20px` | 同左 | 卡片/面板 |
| `--radius-bubble` | `20px` | 同左 | 消息气泡 |

**控件一律胶囊形:** 单行 `Input` / `Button` / `Tag` 使用 `--radius-control`;`Textarea` 使用 `--radius-input-multiline`。

## 3. 字体与密度

- UI 文案:**中文**;系统栈 `system-ui, "PingFang SC", "Noto Sans SC", sans-serif`。
- 会话列表行高约 60px;消息气泡内边距 8×12;侧栏宽 280px。
- 支持 `prefers-reduced-motion`:动画可关或缩短。
- 自定义可聚焦控件须有 `:focus-visible`(令牌 `--focus-ring`)。

## 4. 图标

- 仅用 Lucide SVG(`@lucide/vue`),经 `AppIcon` 统一 `size`/`stroke-width`。
- **禁止** emoji / 字母块冒充功能图标(头像首字可保留为占位)。
- 描边约 `1.75`,尺寸导航 `18`、列表辅标 `16`。

## 5. 布局

```
┌─────────────────────────────────────────┐
│ 顶栏(玻璃拟态):品牌 | 导航(会话/好友) | 主题 | 用户胶囊 ▾ │
├──────────┬──────────────────────────────┤
│ 侧栏内容 │ 主区(聊天 / 好友 / 资料)      │
└──────────┴──────────────────────────────┘
```

- 顶栏为**渐进模糊玻璃层**:`position: sticky` + `backdrop-filter: blur(14px) saturate(160%)` + `var(--surface-glass)`;页面在顶栏下方滚动。
- 用户胶囊 = 头像点 + 用户名 + 下箭头,低对比强调底(`--accent-soft`),点击弹 `NDropdown`(个人资料 / 退出登录);导航不再单列「资料」。

| 路径 | 页面 |
|---|---|
| `/login` | 登录/注册(居中卡片) |
| `/` | 会话 + 聊天(**全宽**工作台) |
| `/friends` | 好友与申请(`.page-centred` 居中列) |
| `/profile` | 资料/密码/注销(`.page-centred` 居中列) |

- 居中列实现见 `frontend/src/styles/layout.css`(`max-width: 840px; margin-inline: auto`)。
- **≤720px:** 顶栏可换行;好友/资料全宽内边距;聊天为列表↔会话单栏切换(返回按钮)。
- 主题切换:先写 CSS 变量,再换 Naive theme;`html.theme-switching` 短暂关闭颜色 transition,减轻错层感。

## 6. 交互状态

| 状态 | 要求 |
|---|---|
| 加载 | Naive `Spin` / `Skeleton`;按钮 `loading` |
| 空 | `NEmpty` + 一句中文引导 |
| 错误 | 展示服务端 `message`(统一包络),禁止吞错 |
| 表单 | 校验规则与 `docs/02` 一致 |
| 消息 | **纯文本**渲染,防 XSS |

## 7. Anti-slop(Hallmark Floor / Reflex)

**禁止:** 紫靛渐变、霓虹 glow、多层大阴影、eyebrow、tracked 全大写标签、无意义统计条、组件内硬编码业务色、emoji 图标。

**允许(IM):** 紧凑列表、未读角标、气泡左右分列、角色说明。

## 8. 与后端契约

所有数据字段以 `docs/02-API约定.md` 为准;前端经 `frontend/src/api/index.ts` 调用,禁止页面拼 URL。
